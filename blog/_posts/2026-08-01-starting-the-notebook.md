This is the first entry in a new notebook.

The purpose of this space is simple: to keep ideas that are too developed for a scratch file, but not yet finished enough for a paper. Some notes may become longer essays. Others may remain short records of a useful question, a failed experiment, or a change in how I understand a problem.

The blog itself is built with Jekyll. Each entry begins as a Markdown file like this one; the shared layout, date, links, and archive page are generated automatically.
